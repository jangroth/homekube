# Infisical is the secret store; sealed-secrets covers only bootstrap

Self-hosted Infisical holds cluster and operator secrets. sealed-secrets stays for bootstrap secrets: what an empty cluster needs to bring Infisical back (Infisical's own keys and database credentials, the Longhorn backup credentials that restore its database), plus Alertmanager's Telegram credentials so an Infisical outage still raises an alert. The sealed-secrets controller runs with `keyrenewperiod: "0"`: renewal never re-sealed old secrets or limited a cluster compromise, and each new key needed a manual export to survive a rebuild. Rotation is manual and is followed by a fresh key export. Because `homekube-apps` is public and its history keeps every sealed ciphertext, each secret gets a new value when it moves to Infisical, so the sealing key only ever decrypts bootstrap secrets and dead values.
